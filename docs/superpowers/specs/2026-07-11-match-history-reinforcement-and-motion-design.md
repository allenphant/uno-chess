# UNO Chess 對局資訊、復活與動態設計

## 目標

將目前規則核心展示頁提升為可清楚操作與驗收的平面對戰介面：修正升變、補齊棋譜回放與墓地、重做復活配置、讓卡面語意一致，並讓所有棋子位移具有動畫。

## 核心原則

- 對局事件是棋譜與未來線上重播的唯一資料來源；畫面不得靠解析卡牌 ID 猜測顯示內容。
- 即時棋局與歷史回看明確分離。回看時棋盤唯讀，玩家可一鍵回到最新局面。
- 棋盤格尺寸固定，棋子與特效不得改變 grid 尺寸。
- 升變、復活等需要補充選擇的操作都先完成選擇，再送出正式 intent。
- 所有文字使用繁體中文；所有卡面圖示直接表達效果，不使用無關棋子裝飾。

## 對局時間軸與回放

`useLocalGame` 保存每次成功 intent 產生的事件以及可回看的狀態檢查點。時間軸顯示：

- 每回合玩家與回合數。
- 打出的 UNO 牌（顏色、名稱）。
- 每一步 SAN 棋譜，例如 `Nf3`、`Qxe5+`、`e8=Q`。
- 復活配置以「復活 ♞ → c3」等文字記錄。

棋譜面板提供四個方向按鈕：開局、上一步、下一步、最新局面。點擊任一棋步可跳到該檢查點。回看時：

- 棋盤顯示該步後的 FEN。
- 手牌與棋盤操作鎖定。
- 顯示「正在查看第 X 步」及「回到目前局面」。
- 新事件到達時不強迫離開使用者正在查看的歷史位置。

`card-played` 事件補上卡牌 kind 與 color，讓事件本身足以呈現。棋步使用規則核心已產生的 SAN，不在 UI 重算。

## 升變

當玩家把兵移到最後一排時，UI 從同一來源／目標的合法棋步取得 `q/r/b/n` 選項，先顯示靠近目標格的升變選擇器。選擇皇后、城堡、主教或騎士後才送出帶有 `promotion` 的 `basic-move` 或 `action-move` intent。取消不消耗行動。

點擊與拖曳移動共用同一個 `requestMove(from, to)` 入口，確保兩種操作都不會漏掉 promotion。

## 墓地與子力資訊

棋盤上下各有一個玩家資訊列，列出該軍團目前被吃掉的棋子。採常見棋站方式顯示棋子群組與子力差，但墓地資料直接讀取 `board.capturedByArmy`。

復活階段時，可復活的墓地棋子變成按鈕；不可復活的棋子仍顯示但呈停用狀態。棋子價值只用於顯示子力差：兵 1、馬 3、象 3、車 5、后 9，王不計分。

## 復活配置

復活採逐枚配置：

1. 從墓地選擇一枚可復活棋子。
2. 棋盤只標示這枚棋子的合法落點。
3. 指向或觸碰合法格時顯示半透明棋子虛影。
4. 點擊落點後產生配置項目，例如「♞ → c3」。
5. 可再選第二枚，或在一枚時直接完成。
6. 每項配置都可撤銷；「完成復活」顯示 `1/2` 或 `2/2`。

只有按下完成後才送出一次 `choose-reinforcement` intent。已配置的虛影會留在棋盤上，並且後續合法格計算要排除已佔用格。若撤銷，該棋子回到墓地可再次選擇。

## 卡面語意

卡面中央改成不綁定特定棋種的效果符號：

- 行動 2：`2×`，說明「本回合最多移動 2 步」。
- 行動 3：`3×`，說明「本回合最多移動 3 步」。
- 援軍：`+2`，說明「復活最多 2 枚棋子」。
- 封印：`LOCK`，說明「對手下回合不能出牌」。
- 反轉：`SWAP`，說明「交換雙方手牌」。
- 變節：`FLIP`，說明「交換棋軍控制權」。

保留顏色、名稱、短效果文字與 UNO 式大字視覺，不再使用與效果無關的國王、城堡或騎士符號。

## 棋子動畫

棋盤以穩定的方格層與絕對定位棋子層呈現。棋子用可辨識的穩定 identity（優先使用 `activePieces` 的 piece id）從舊座標 transition 到新座標：

- 一般移動與王車易位：220ms ease-out 滑動。
- 吃子：被吃棋子在移動結束時淡出縮小。
- 復活：棋子由墓地語意上的縮小／淡入狀態進入目標格。
- 升變：兵先移動到目標，再切換成所選棋種。

動畫期間阻止同一棋子重複送出操作，但不延遲規則狀態更新。`prefers-reduced-motion: reduce` 時關閉位移動畫。

## 響應式與可及性

- 桌面版棋盤在左、棋譜在右；窄螢幕棋譜移至棋盤下方。
- 方向按鈕有中文 `aria-label`，並支援鍵盤 Home、ArrowLeft、ArrowRight、End。
- 升變與復活選擇器可用鍵盤操作，虛影不取代清楚文字。
- 回看模式以文字與視覺邊框同時標示，不只靠顏色。

## 驗收範圍

- 兵到最後一排不再報錯，四種升變都能選擇。
- 每次出牌、移動與復活都出現在棋譜；四個方向鍵和點擊棋步可回看。
- 雙方墓地與子力差正確。
- 復活一枚或兩枚都能完成，選擇、落點、虛影與撤銷皆清楚。
- 卡面無無關棋子圖示。
- 一般移動、吃子、王車易位、復活與升變不再瞬發；減少動態設定下不動畫。
