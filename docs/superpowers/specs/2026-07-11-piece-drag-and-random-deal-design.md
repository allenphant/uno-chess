# 棋子直接拖曳、全棋盤出牌區與隨機起手牌設計

## 目標

讓玩家可以直接拖曳可移動的西洋棋棋子；出牌時整張棋盤都是落點；每次建立本機對局都有新的洗牌種子，避免重載後永遠看到同一組同色起手牌。

## 棋子拖曳

- 只有目前玩家可合法移動的己方棋子能開始拖曳。
- 指標或手指移動超過 8px 才進入拖曳，短觸仍保留原有點擊選棋方式。
- 進入拖曳時，來源棋子的字形跟隨指標；棋盤格本身不移動、不縮放，也不改變 8×8 尺寸。
- 同時顯示該棋子的所有合法落點。
- 在合法格放開時直接送出既有的 basic-move 或 action-move 意圖。
- 在非法格、棋盤外或取消手勢時，棋子回到原格，不改變規則狀態。
- 成功拖曳後的合成 click 必須被忽略，避免落子後又選取棋格。

## 全棋盤出牌區

- 只有可出的 UNO 卡牌進入拖曳後，才顯示出牌層。
- 出牌層絕對定位覆蓋完整棋盤舞台；棋盤任何位置均視為有效出牌目標。
- 出牌層為半透明，保留棋盤可見性；中央提示改為「放開以出牌」。
- 出牌期間棋盤的走棋互動鎖定，防止卡牌手勢誤觸棋子。
- 卡牌在棋盤外放開則回到手牌，不提交出牌意圖。

## 起手牌隨機性

- App 只在建立一局本機遊戲時產生一次新 seed；同一局中的 reducer 更新不應重設牌局。
- seed 使用瀏覽器安全亂數 UUID；若瀏覽器不支援則使用時間戳與隨機值組合。
- 規則引擎仍接受 seed 並使用 deterministic shuffle，因此對局記錄可以重播。
- 真正的隨機發牌仍可能偶然出現同色手牌；本次修正的目標是移除每次重載必定相同的結果，而非強制牌色均衡。

## 測試與驗收

- 新 seed 產生器在連續建立時產生不同值，且 App 在一次 mounted lifecycle 中維持同一 seed。
- 棋子拖曳只在超過門檻後開始；合法格提交一次，非法格與取消不提交。
- 拖曳開始時通知父層以顯示正確合法格；成功拖曳不觸發 click 選格。
- 出牌層 active 時其矩形覆蓋整個棋盤舞台，且帶有 card drop-zone 標記。
- CSS 契約驗證棋子拖曳使用 `.piece.dragging`，不對 `.square.dragging` 使用 transform。
- 瀏覽器手動驗收：拖一枚兵到合法前進格、拖到非法格回彈、拖一張合法牌到棋盤任意角落、重新載入兩次觀察不同起手牌。
