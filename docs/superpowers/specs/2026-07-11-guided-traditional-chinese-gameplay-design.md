# 繁體中文引導與初版卡面設計

## 目標

讓第一次進入本機對局的玩家不需要理解內部 phase 或英文規則，也能立即知道目前發生什麼事、下一步能做什麼，並能從卡面快速辨識牌色、牌種與效果。

## 自動抽牌

- 每次進入 `turn-start` 時，由本機控制器自動送出一次 `draw-for-turn` 意圖。
- 畫面短暫顯示「正在自動抽牌……」，不再提供手動「抽牌」按鈕。
- 自動抽牌仍完全走既有 reducer，因此重播、事件、手牌上限與隨機種子行為不變。
- 若抽牌後超過五張，立即進入強制棄牌引導；完成棄牌後才開放出牌或基本移動。
- React Strict Mode 或重繪不得造成重複抽牌；intent ID 與 reducer 的 phase 驗證共同保護一次性行為。

## 繁體中文介面

- 玩家可見文字全部改為繁體中文，包括標題、回合、牌庫、階段提示、按鈕、錯誤訊息、功能選擇與卡面說明。
- 第一版只提供繁體中文，不先建立多語系框架；文字集中到 `uiText.ts`，方便後續再加入語言切換。
- 內部穩定 ID、牌種 ID、phase、intent 與規則快照保持英文，不影響歷史對局與重播。
- 玩家顯示名稱暫用「玩家 1」「玩家 2」，不直接顯示 `p1`、`p2`。

## 當前行動引導

棋盤上方或側欄顯示一個高優先級引導區，依 reducer 狀態產生唯一主要訊息：

- `turn-start`：正在自動抽牌……
- `await-overflow-discard`：手牌已滿，請選一張牌棄掉。
- `await-action`：請打出一張可用手牌，或直接移動一枚棋子。
- `await-action-move`：行動牌生效中；顯示剩餘移動次數，也可提前結束。
- `await-effect-choice` + `wild-color`：請選擇新的牌色。
- `await-effect-choice` + `reinforce`：請選擇要復活的棋子，再放到亮起的格子。
- 對局結束：顯示勝負或和局原因並停用操作。

引導必須使用 `aria-live`，並以文字搭配圖示，不只依賴顏色。合法手牌仍由既有 UNO 配對規則決定；不可出的牌維持 disabled。

## 初版卡面：棋戰徽章

每張牌使用一致的三段式結構：

1. 上方：牌色圓點與繁體中文牌名。
2. 中央：大型棋戰符號或數字，作為快速辨識核心。
3. 下方：一行簡短效果說明。

牌面內容：

| 牌種 ID | 中文牌名 | 中央符號 | 效果說明 |
| --- | --- | --- | --- |
| `action-2` | 行動牌 2 | `♞ ×2` | 最多移動兩次 |
| `action-3` | 行動牌 3 | `♜ ×3` | 最多移動三次 |
| `reinforce` | 援軍 +2 | `♟ ↥ ♞` | 復活最多兩枚棋子 |
| `seal` | 封印 | `♚ ⛓` | 對手下回合不能出牌 |
| `reverse` | 交換 | `⇄` | 雙方交換整副手牌 |
| `betray` | 變節 | `♚ ⇄ ♔` | 交換軍隊並選擇牌色 |

- 有色牌保留紅、黃、綠、藍主色，使用白色內框與深色陰影。
- 變節牌使用四色分區背景，牌名和說明保持高對比。
- 小螢幕仍需看見牌名和中央符號；效果說明可縮小但不可完全隱藏。
- 卡牌的 accessible name 包含中文牌名、顏色與效果摘要。

## 元件邊界

- `useLocalGame`：負責 phase 驅動的自動抽牌，仍以 reducer 作為唯一狀態來源。
- `uiText.ts`：集中玩家名稱、牌名、牌色、階段、錯誤碼與結果文字。
- `TurnGuide`：只接收 `GameState` 並產生主要引導，不送出 intent。
- `CardFace`：只負責卡面呈現與 accessible label；`CardHand` 保留選取與拖曳責任。
- `TurnPanel`：顯示中文公開資訊，不再擁有抽牌按鈕。

## 測試與驗收

- 自動抽牌測試證明每回合只抽一次，並能進入超額棄牌狀態。
- 元件測試覆蓋所有主要 phase 的繁體中文引導。
- 卡面表格測試覆蓋六種核心牌的中文名稱、符號、說明與 accessible name。
- 既有點擊、拖曳、UNO 配對、功能牌、重播和規則測試必須保持通過。
- 桌機與 390×844 手機畫面手動確認：引導可見、卡面可讀、無水平溢出。
